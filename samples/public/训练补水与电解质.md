# 训练补水与电解质（公共知识库）

本文给出训练前中后的补水方法与电解质补充时机。依据：ACSM 运动与补液立场声明、NATA 补液共识。

## 一、训练前

1. 训练前 2 小时喝 400~600ml 水，给身体时间平衡水分。
2. 训练前 15~20 分钟再喝 150~250ml，避免胃里太撑。
3. 尿液呈淡黄色说明水分基本充足；深黄说明需要补。
4. 咖啡和茶可以计入总水分，不必因为"利尿"而额外多喝。

## 二、训练中

1. 每 15~20 分钟补 150~250ml，小口多次，不要一次猛灌。
2. 训练超过 60~90 分钟、或大量出汗时，才需要含电解质的运动饮料。
3. 钠浓度参考 300~700mg/L；自己配可用 1L 水 + 1~2g 盐 + 少量糖。
4. 脱水达到体重的 2% 就会明显影响力量、耐力与认知。

## 三、训练后

1. 训练后 2 小时内补回丢失体重的 100%~150% 的水分。
2. 估算出汗量：训练前后体重差（kg）× 1000 ≈ 丢失的毫升数，再加上训练中喝的量。
3. 大量出汗后只喝白水可能稀释血钠，长距离运动应搭配电解质。
4. 酒精会加重脱水并抑制恢复，训练后 2 小时内尽量不喝。

## 四、热环境与特殊情况

1. 高温高湿环境需要 1~2 周热适应，期间降低强度 10%~20%。
2. 出现头晕、恶心、停止出汗、意识模糊，可能是热病前兆，立即停止并降温就医。
3. 肾功能不全、心衰、需限水者，补液方案必须遵医嘱。
4. 减重期不要用"脱水"制造体重下降，会影响训练表现与恢复。
