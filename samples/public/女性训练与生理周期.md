# 女性训练与生理周期（公共知识库）

本文说明女性力量训练要点、月经周期与孕期运动的注意事项。依据：ACSM 孕期运动指南、国际奥委会女性运动员共识。

## 一、训练原则与男性没有本质差别

1. 女性同样适合大重量、低次数的抗阻训练，不存在"练重量会变金刚芭比"。
2. 增肌所需的组数、频率、渐进方式与男性一致：每肌群每周 10~20 组、每周 2 次。
3. 上肢力量起点通常较低，可从更轻负荷开始，进步速度并不慢。
4. 不要只做有氧和轻重量：抗阻训练对体成分、骨密度和胰岛素敏感性都更关键。

## 二、月经周期怎么调训练

1. 周期对运动表现的影响个体差异很大，平均效应很小，不必据此大幅改计划。
2. 黄体期基础体温略升、耐热能力下降，可适当降低强度或延长休息。
3. 经期可以继续训练，按主观感受减量即可；痛经严重时改为散步或拉伸。
4. 建议记录周期与训练感受 2~3 个周期，找出自己的规律，而不是照搬别人的模板。

## 三、孕期与产后

1. 无禁忌症时，孕期推荐每周 150 分钟中等强度运动，如快走、游泳、固定单车。
2. 避免接触性运动、有跌倒风险的项目、高温环境，以及孕中晚期长时间仰卧。
3. 产后先从呼吸与盆底肌训练开始，逐步恢复；腹直肌分离明显者先做康复评估。
4. 出现出血、规律宫缩、头晕胸痛等情况立即停止并就医。

## 四、营养与骨健康

1. 女性缺铁风险较高，月经量大、素食或长期疲劳者建议查铁蛋白。
2. 长期低热量 + 高训练量可能导致月经紊乱（能量可用性不足），需要增加摄入并减少消耗。
3. 抗阻 + 负重运动 + 足量蛋白（1.6g/kg）+ 维生素 D，是维护骨密度的基础。
