# 居家与出差训练方案（公共知识库）

本文给出没有健身房时的训练安排，重点是"维持"而不是"归零"。依据：自重训练进阶研究、ACSM 抗阻训练立场声明。

## 一、没有器械能练到什么程度

1. 自重训练对新手前 8~12 周足以带来力量与肌肉增长。
2. 后期靠增加难度而非增加次数：单侧动作、放慢离心、缩短休息、增加负重。
3. 每周 2 次全身训练、每次 20~30 分钟，基本可以维持已有力量与肌肉。
4. 出差 3~5 天不练不会掉肌肉，真正掉肌肉的是连续 2~3 周的低活动量。

## 二、自重动作进阶路线

1. 下肢：深蹲 → 保加利亚分腿蹲 → 单腿蹲（手枪蹲辅助版）。
2. 上肢推：跪姿俯卧撑 → 标准俯卧撑 → 下斜俯卧撑 → 负重俯卧撑。
3. 上肢拉：毛巾划船 → 弹力带划船 → 引体向上（可用弹力带辅助）。
4. 髋与核心：臀桥 → 单腿臀桥 → 平板支撑 → 侧平板。

## 三、20 分钟循环模板

1. 选 5 个动作：深蹲、俯卧撑、臀桥、划船、平板支撑。
2. 每个动作做 40 秒、休 20 秒，5 个动作为一轮，做 3~4 轮。
3. 循环训练心率可到最大心率的 70%~80%，兼具力量与心肺刺激。
4. 每周 2~3 次，隔天进行；强度以第二天不明显酸痛为准。

## 四、出差与酒店房间

1. 15 分钟版：深蹲 3×20、俯卧撑 3×15、臀桥 3×20、弓步 3×12/腿、平板 3×40 秒。
2. 带一根弹力带即可完成划船、推举、侧平举、面拉。
3. 把"走路"也算训练：每天 8000 步以上的活动量能显著减缓力量流失。
4. 回到健身房后前 1~2 周先降到原重量的 80%~90%，再恢复原计划。
